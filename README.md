# Drink Store

Full-stack веб-приложение (интернет-магазин напитков) с упором на безопасную архитектуру, кастомную логику пользователей и контейнеризацию.

## Технологический стек

* **Backend:** Python 3.11, Django, Django REST Framework (DRF)
* **Frontend:** React (Vite), JavaScript, CSS3
* **Database:** PostgreSQL 15
* **Infrastructure:** Docker
* **Environment:** Debian 13 (Development)

----------------------------------------------------------------------------------------------------------------------

## Архитектура проекта

Проект реализован как монорепозиторий с разделением ответственности:
* `/backend` — API сервис на Django с расширенной моделью пользователя.
* `/frontend` — Клиентская часть на React (Vite).
* `docker-compose.yml` — Инфраструктура, объединяющая сервисы и базу данных.

## Roadmap

### 1. User & Security
* **Кастомная модель пользователя:** Переход от стандартного `User` к `AbstractUser` для добавления специфичных полей (возраст, баланс, телефон).
* **JWT Auth:** Реализация авторизации через Access/Refresh токены (Simple JWT).
* **Валидация возраста:** Логика запрета доступа к определенным категориям товаров для лиц младше 18 лет.

### 2. Магазин и корзина
* **Каталог товаров:** Система фильтрации напитков по категориям, крепости и цене.
* **Smart Cart:** Логика корзины с сохранением состояния для авторизованных пользователей.
* **История заказов:** Личный кабинет с возможностью просмотра прошлых покупок.

### 3. Dev & UI
* **UI Kit:** Создание собственной библиотеки компонентов (Modals, Buttons, Inputs).
* **Production Build:** Оптимизация Docker-образов (multi-stage builds) для деплоя.
* **API Docs:** Интеграция Swagger/Redoc для документирования эндпоинтов.

## Инструкция по запуску

Для запуска необходимо иметь установленный Docker.

1.  **Клон репо**
    ```bash
    git clone github.com/malyshauv/drinkstore
    cd drinkstore
    ```

2.  **Сборка контейнеров**
    ```bash
    docker compose up --build
    ```

3.  **Миграции**
    ```bash
    docker compose exec backend python manage.py migrate
    ```
